# Getting started

Everything here comes from a small tree compiled into the kernel, copied to the
root disk the first time FEOS boots on it.

Try the explorer:

1. Click Start, or press Space, to open the Start menu.
2. Choose **File Explorer**.
3. Double-click a folder to open it, or use the arrow keys, Enter and Backspace.
4. Close the window when you're done.

The same files are in the shell, in a Terminal window or on the serial console:

```text
ls /docs
cat /README.txt
tree /
files ls /docs
```
