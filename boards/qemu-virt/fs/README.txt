feos
====

Welcome to your new feos machine.

This file lives on the read-only filesystem that is compiled into the kernel.
Use the File Explorer from the Start menu, or the shell commands:

  files              open the graphical file explorer
  files ls [path]    list a directory
  files cat <path>   print a text file
  files tree [path]  print the whole tree
  files stat <path>  show file details
