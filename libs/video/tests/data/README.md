# Video test fixtures

The clips in this directory are tiny (32x32, four-frame) files generated with
FFmpeg so the integration tests can exercise every container without checking
large binaries into the repository.

The `ref_*.rgba` files are the matching frame 0 (or frame 1 for
`ref_gif_1.rgba` / `ref_mp4_1.rgba`) decoded by FFmpeg into packed RGBA8888:

```sh
ffmpeg -i clip.mp4 -frames:v 1 -pix_fmt rgba -f rawvideo ref_mp4_0.rgba
```

The tests compare the decoder output against these references with a small
tolerance for IDCT rounding and H.264 chroma upsampling. Regenerate a fixture
with any `testsrc`/`smptebars` source at 32x32 and 10 fps, then rebuild the
matching reference with the command above.

The other clips, generated by `generate.py` (which lists the exact commands),
cover what the original set can't: B-frames in every container, fragmented and
rotated MP4, anamorphic and full-range BT.709 video, variable frame rate, raw
AVI at widths not divisible by 4, and RLE delta frames.

## Real AAC streams

Fractions of a second of ISO conformance streams from FFmpeg's FATE suite (`fate-suite/aac`), for
what no encoder at hand makes, each with FFmpeg's decoding of the cut:

```sh
cut() { ffmpeg -v error -y -i $FATE/$1 -c copy -t $3 -map_metadata -1 -fflags +bitexact -movflags +faststart $2
        ffmpeg -v error -y -i $2 -f s16le -c:a pcm_s16le -fflags +bitexact $2.s16; }
cut al04sf_48.mp4 aac-960.mp4 0.5                # 960-sample frames
cut ap05_48.mp4 aac-ltp.mp4 0.5                  # LTP
cut am00_88.mp4 aac-main.mp4 0.4                 # Main, 88.2 kHz
cut al04_44.mp4 aac-pulse.mp4 0.5                # pulse data
cut al_sbr_cm_48_2.mp4 he-sbr.mp4 0.6            # SBR
cut al_sbr_ps_06_new.mp4 he-ps.mp4 0.6           # parametric stereo
cut al_sbr_ps_04_new.mp4 he-ps-phase.mp4 0.6     # with IPD and OPD
cut al_sbr_sr_48_2_fsaac48.mp4 he-downsampled.mp4 0.6   # SBR with output at the core's rate
```

`av-frag.mp4` has sound in its fragments:

```sh
ffmpeg -y -f lavfi -i testsrc2=s=64x48:r=5:d=1 -f lavfi -i sine=f=440:r=48000:d=1 -c:v libx264 -preset ultrafast -g 2 \
    -pix_fmt yuv420p -c:a aac -b:a 64k -fflags +bitexact -movflags +frag_keyframe+empty_moov+default_base_moof av-frag.mp4
```
