# Test fixtures

`tests/gen_fixtures.py` writes every file below except those under "Older
fixtures", using python3 with Pillow, and ffmpeg. The files are committed, so
tests never need those tools. To regenerate:

```sh
python3 libs/image/tests/gen_fixtures.py
```

Generated with Pillow 12.1.1 (libjpeg-turbo 8.0 API) and the system ffmpeg. Other
versions may produce different bytes, which is fine as long as the tests pass.

`tests/fuzz.rs` seeds from every file here that `feos_image::detect` recognises,
so a new fixture also joins the mutation test.

## JPEG

ffmpeg's `mjpeg` encoder has no progressive mode, and no tool here writes unusual
sampling or separate scans, so these come from Pillow and the small encoder in
the script. That encoder codes the same 37x29 picture to the same coefficients
whatever the scan layout, so the tests can require identical pixels.

| File | How | Tests |
|------|-----|-------|
| `gray_h1v1.jpg`, `gray_h2v2.jpg` | script; one component, SOF sampling 1x1 and 2x2 | sampling is ignored for a lone component |
| `interleaved_420.jpg`, `restart_420.jpg` | script; one scan, no restarts and DRI=2 | allocation-free path |
| `multiscan_420.jpg`, `multiscan_restart_420.jpg`, `multiscan_y_cbcr_420.jpg` | script; one scan per component, with DRI=3, and Y then CbCr | coefficient path equals `interleaved_420.jpg` |
| `reversed_scan_420.jpg` | script; SOS lists components in reverse | MCU order follows the scan |
| `sampling_h4v2.jpg` | script; Y 4x2, chroma 1x1, 10 blocks an MCU | `h*v > 4` |
| `sampling_h4v4.jpg`, `sampling_doubled_444.jpg` | script; 18 and 12 blocks an MCU | over the T.81 limit; libjpeg refuses these |
| `interleaved_444.jpg` | script | reference for the sampling tests |
| `rgb_ids.jpg` | script; no JFIF or Adobe, component ids `R`, `G`, `B` | RGB by id |
| `adobe_rgb.jpg`, `adobe_rgb.rgb` | `save(keep_rgb=True, subsampling=0, quality=90)`; libjpeg's decode | Adobe transform 0 |
| `cmyk.jpg`, `cmyk.rgb` | `save(quality=95)` of a CMYK image; libjpeg's decode via Pillow | Adobe CMYK inversion |
| `ycck.jpg`, `ycck.rgb` | script; Adobe transform 2; libjpeg's decode via Pillow | YCCK |
| `with_dht.jpg`, `no_dht.jpg` | `save(quality=75, optimize=False, subsampling=0)`, then DHT removed | standard Huffman tables |
| `no_dht_ffmpeg.jpg` | `ffmpeg -i s.png -c:v mjpeg -q:v 5 -huffman 0 -pix_fmt yuvj420p -frames:v 1`, then DHT removed | same, from a real MJPEG encoder |
| `baseline_{420,444,gray}.jpg`, `progressive_{420,444,gray}.jpg` | `save(quality=80, progressive=True/False)`, with `subsampling=2/0` | progressive equals its baseline twin |
| `baseline_444.rgb` | libjpeg's decode of `baseline_444.jpg` | IDCT and colour against a reference |
| `progressive_restart_420.jpg` | as above, with `restart_marker_blocks=2` | restarts in progressive scans |

## BMP

Hand-built by the script. 8x6 pixels unless noted.

| File | Contents |
|------|----------|
| `pal8.bmp`, `rle8.bmp` | 8-bit palette; RLE8 of the same picture with runs, a padded odd literal, a delta, end of line and end of bitmap |
| `pal4.bmp`, `rle4.bmp` | the same at 4 bits |
| `rgb555.bmp`, `bf565.bmp` | 16-bit default 5-5-5; `BI_BITFIELDS` 5-6-5 |
| `bf32_rgba.bmp` | 56-byte header, masks R=FF000000 G=00FF0000 B=0000FF00 A=000000FF |
| `bf32_noalpha.bmp` | 40-byte header, `BI_BITFIELDS`, same RGB masks and no alpha |
| `bf32_alpha6.bmp` | 40-byte header, `BI_ALPHABITFIELDS` with four masks |
| `topdown24.bmp` | 24-bit, negative height |

## PNG

Hand-built by the script with Python's `zlib`.

| File | Contents |
|------|----------|
| `gray1.png`, `gray2.png`, `gray4.png` | packed gray, 8x4 |
| `rgb16.png`, `rgba16.png` | 16 bits per channel, 6x5, with a low byte that must be dropped |
| `adam7_rgb16.png` | `rgb16.png` as Adam7 |
| `idat_split.png` | `rgb16.png` with IDAT split around a tEXt chunk |
| `trns_gray8.png`, `trns_rgb16.png` | `tRNS` colour keys; the RGB pair differs only in a low byte |
| `short_idat.png`, `long_idat.png` | valid zlib holding too little and too much data; must be rejected |

## Netpbm and QOI

| File | How |
|------|-----|
| `p1.pbm`, `p2.pgm`, `p3.ppm` | script; ASCII, with comments, P1 digits run together |
| `p4.pbm`, `p5.pgm`, `p6.ppm`, `p5_16.pgm` | script; the same pictures in binary, the last at maxval 1023 |
