FEOS-DOS GAME LIBRARY
=====================

All titles are Shareware, Demo or Freeware (DOSGames.com).
Use MOUNT <name> to extract a ZIP into C:\<name>.

doom.zip
  DOOM - id Software - needs DOS/4GW protected mode
duke-nukem-3d.zip
  Duke Nukem 3D - 3D Realms - needs DOS/4GW protected mode
wolfenstein-3d.zip
  Wolfenstein 3D - id Software - 16-bit, VGA mode 13h
quake.zip
  Quake - id Software - needs DJGPP/go32 extender
super-street-fighter-ii-turbo.zip
  Super Street Fighter II Turbo demo - needs 32RTM extender
tank-wars.zip
  Tank Wars - 16-bit, VGA mode 13h
warcraft-2-tides-of-darkness.zip
  Warcraft II demo - Blizzard - needs DOS/4GW protected mode
champ-kong.zip
  Champ Kong - 16-bit
galacta-the-battle-for-saturn.zip
  Galacta - 16-bit, CGA/EGA
mario-bros-vga.zip
  Mario Bros VGA - 16-bit, VGA
simcity-2000.zip
  SimCity 2000 demo - Maxis - needs DOS/4G protected mode
snood.zip
  Snood - needs CWSDPMI protected mode
digger-remastered.zip
  Digger Remastered - freeware - 16-bit, CGA

The DOS/4GW, DOS/4G, DJGPP and CWSDPMI titles need 386 protected
mode and DOS extenders, which are not implemented yet.
