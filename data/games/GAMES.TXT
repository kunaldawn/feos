FEOS-DOS GAME LIBRARY
=====================

The DOSGames.com site labels these Shareware, Demo or Freeware. Each
title's own terms are in its ZIP: see data/games/README.md.
Use MOUNT <name> to extract a ZIP into C:\<name>.

doom.zip
  DOOM - id Software - DOS/4GW
duke-nukem-3d.zip
  Duke Nukem 3D - 3D Realms - DOS/4GW
wolfenstein-3d.zip
  Wolfenstein 3D - id Software - real mode, VGA, EMS
quake.zip
  Quake - id Software - DJGPP, the DPMI host
super-street-fighter-ii-turbo.zip
  Super Street Fighter II Turbo demo - 32RTM, needs the SB16
tank-wars.zip
  Tank Wars - real mode, VGA
warcraft-2-tides-of-darkness.zip
  Warcraft II demo - Blizzard - DOS/4GW, needs the SB16
champ-kong.zip
  Champ Kong - real mode, VGA
galacta-the-battle-for-saturn.zip
  Galacta - real mode, VGA
mario-bros-vga.zip
  Mario Bros VGA - real mode, VGA
simcity-2000.zip
  SimCity 2000 demo - Maxis - DOS/4G, VESA
snood.zip
  Snood - DJGPP, the DPMI host, VESA
digger-remastered.zip
  Digger Remastered - freeware - real mode, VGA

All of them run. SBTYPE, DPMI and EMM386 change the machine:
type HELP. See docs/dosbox.md for what each title reached.
